🚀 Demo de Integração

Demonstração de como integrar o sistema de campos personalizados com sua aplicação

1 Registrar Seções do Sistema

Primeiro, sua aplicação precisa registrar quais seções/telas possui:

const sections = [
  {
    id: 'basic-info',
    name: 'basic_info',
    label: 'Informações Básicas'
  },
  {
    id: 'processes',
    name: 'processes',
    label: 'Processos Impactados'
  },
  // ... outras seções
];

fetch('http://localhost:3002/api/sections/register', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ sections })
});
2 Acessar Painel Administrativo

Após registrar as seções, o admin pode acessar o painel para configurar campos:

📋 No painel admin você pode:
  • Ver todas as seções registradas
  • Adicionar campos personalizados em cada seção
  • Editar e excluir campos existentes
  • Reordenar campos por drag & drop
  • Configurar validações e tipos de campo
🎨 Abrir Painel Admin
3 Carregar Campos Dinâmicos no Formulário

Sua aplicação carrega e renderiza os campos configurados:

// Buscar campos de uma seção
const response = await fetch(
  'http://localhost:3002/api/custom-fields?section=processes'
);
const { data: fields } = await response.json();

// Renderizar cada campo dinamicamente
fields.forEach(field => {
  renderDynamicField(field);
});

// Salvar valores
await fetch('http://localhost:3002/api/forms/values', {
  method: 'POST',
  body: JSON.stringify({
    values: [
      { field_id: 'xxx', analysis_id: 'yyy', value: '...' }
    ]
  })
});
