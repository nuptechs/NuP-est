📱 PADRÕES DE UX
Layout e Estrutura:
Sidebar fixa no lado esquerdo (desktop)
Header/Navbar no topo com breadcrumbs e ações
Conteúdo principal centralizado com padding apropriado
Background: #FAFAFA (quase branco) para área principal
Estados Interativos:
Hover: Suave transição de cor (200ms ease)
Focus: Ring roxo hsl(263.4, 70%, 50.4%) com offset
Active: Cor mais escura/saturada
Disabled: Opacidade 50% + cursor not-allowed
Feedback Visual:
Loading states: Skeletons com animação pulse
Success: Toast verde com ícone de check
Error: Toast vermelho com mensagem clara
Warning: Toast amarelo/laranja
Formulários:
Labels acima dos inputs
Placeholders com opacidade 60-70%
Validação em tempo real com mensagens abaixo do campo
Botões de ação primária sempre à direita
Campos obrigatórios com indicador visual
Placeholders:
Tamanho: text-sm (0.875rem)
Cor Light Mode: #9ca3af (gray-400) com opacity 0.7
Cor Dark Mode: hsl(var(--muted-foreground)) com opacity 0.6
🌓 DARK MODE
Sistema completo de dark mode com toggle:

Implementação:

darkMode: ["class"] no Tailwind
Classe .dark no elemento root para ativar
Todas as cores têm variantes dark definidas
Transição suave entre modos
Cores Dark Mode:

Background: hsl(0, 0%, 0%) (preto puro)
Card: hsl(228, 9.8%, 10%) (quase preto)
Muted: hsl(0, 0%, 9.4%)
Border: hsl(210, 5.3%, 14.9%)
✨ ANIMAÇÕES
Use animações sutis e performáticas:

Accordion: Expand/collapse com ease-out (200ms)
Transitions: All transitions em 200ms
Hover effects: Transform scale(1.02) ou brightness
Loading: Pulse animation para skeletons
🎨 APLICAR EM NUPIDENTITY
Páginas que devem seguir este design:

Login/Register - Card centralizado, gradiente de fundo sutil
Dashboard - Layout com sidebar + conteúdo principal
Gerenciamento de Usuários - Tabela com ações, filtros, paginação
Gerenciamento de Sistemas - Cards ou lista com badges de status
Permissões e Perfis - Interface tipo admin panel
Configurações - Tabs com seções (Perfil, Segurança, Notificações, etc)
