🔑 Como Obter o IDENTITY_SYNC_TOKEN
O IDENTITY_SYNC_TOKEN é um token JWT de administrador que vem do projeto NuPIdentify (o novo projeto separado que você criou).

📋 Passo a Passo:
1️⃣ No Projeto NuPIdentify (novo projeto):
Primeiro, configure o NuPIdentify:

# 1. Criar banco PostgreSQL
Tools → Database → Add PostgreSQL Database
# 2. Configurar Secrets
JWT_SECRET=chave-secreta-jwt-2025
JWT_REFRESH_SECRET=chave-refresh-jwt-2025
SESSION_SECRET=chave-sessao-2025
# 3. Instalar e inicializar
npm install
npm run db:push
npm run db:seed      # Cria usuário admin padrão
npm run dev          # Inicia servidor
2️⃣ Fazer Login como Admin:
Após o db:seed, um usuário admin é criado. Faça login:

# Via curl (se souber a senha do seed):
curl -X POST https://nupidentify.replit.dev/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "admin@nuptechs.com",
    "password": "SENHA_DO_SEED"
  }'
# OU via interface web:
# 1. Abra: https://nupidentify.replit.dev
# 2. Faça login com o usuário admin
# 3. Abra DevTools (F12) → Console
# 4. Execute: localStorage.getItem('token')
3️⃣ Copiar o Token:
A resposta do login retorna algo assim:

{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOiIxMjMiLCJlbWFpbCI6ImFkbWluQG51cHRlY2hzLmNvbSIsImlhdCI6MTcwMDAwMDAwMCwiZXhwIjoxNzAwMDg2NDAwfQ.abc123...",
  "refreshToken": "...",
  "user": { ... }
}
Copie o valor do campo "token" (o JWT longo)

4️⃣ Neste Projeto (NuP-Kan):
Cole o token nas Secrets:

Tools → Secrets
Adicione:
# Nome da Secret
IDENTITY_SYNC_TOKEN
# Valor (cole o token JWT copiado)
eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJ1c2VySWQiOiIxMjMi...
Adicione também:
# Nome
IDENTITY_URL
# Valor
https://nupidentify.replit.dev
Reinicie o servidor (Stop → Run ou Ctrl+C e npm run dev)
🔍 Verificar se Funcionou:
Após reiniciar, procure nos logs por:
